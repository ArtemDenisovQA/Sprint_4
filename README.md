# Sprint_4 — UI автотесты (Яндекс Практикум)

Учебный проект 4 спринта: автоматизированные UI-тесты веб-приложения на **Java**.  
Проект собирается через **Maven**, для тестирования используется **Selenium WebDriver** и **JUnit 4**.

## Что в проекте

Проект предназначен для проверки пользовательских сценариев в веб-интерфейсе (UI), например:

- переходы между страницами;
- авторизация / работа с формами;
- проверки элементов интерфейса;
- позитивные и негативные сценарии взаимодействия.

> Точный набор сценариев зависит от тестовых классов в `src/test/java`.

## Технологии

- **Java 11**
- **Maven**
- **JUnit 4.13.2**
- **Selenium WebDriver 4.10.0**
- **WebDriverManager 5.5.3**

## Структура проекта

```text
src/
 ├─ main/
 │   └─ java/              # page object / вспомогательные классы (если используются)
 └─ test/
     └─ java/              # UI-тесты
pom.xml
README.md
```

## Как запустить тесты

### Предварительно
Убедись, что у тебя установлены:

- **JDK 11**
- **Maven**

### Запуск всех тестов

```bash
mvn clean test
```

## Полезно знать

- Все зависимости и версии библиотек находятся в `pom.xml`.
- Драйверы браузеров подтягиваются через **WebDriverManager**.
- При необходимости параметры запуска (браузер, URL и т.п.) можно вынести в конфиг/константы.
